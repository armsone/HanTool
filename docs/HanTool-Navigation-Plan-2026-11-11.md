## 1. 확정 10대 계층 내비게이션 트리 구조

성격이 다른 기능을 임의로 합치지 않고 10개 상위 메뉴(주요 목적 8개 + 시스템 2개)로 체계화했습니다.

```text
[왼쪽 계층형 사이드바 트리: 상위 10개 메뉴]
1. 브라우저 (globe)
   └ 하위: 새 탭 추가 (+), 열린 탭 목록 (위치 리프), 독립 탭 닫기 버튼 (마지막 탭 보호)
2. 다운로드 (arrow.down.circle)
   ├ 위치 리프: 진행 중, 완료 기록
   └ 명시적 액션: '주소 직접 입력' (입력칸 포커스 전용), '링크 붙여넣고 받기' (클립보드 즉시 일괄 다운로드)
3. 플래너 (checklist)
   └ 하위: 로컬 프로젝트 목록 (기존 SAWWorkspace 중계 관찰, NAS 내부 미조회)
4. 번역 (character.book.closed)
   └ 하위: 메일 번역(이미지 포함), 화면 번역, 번역 확장
5. 입력 도우미 (keyboard)
   └ 하위: 앱별 입력 언어, 한글 교정 및 번역, 개인 사전, 트랙패드 잠금 (4개 세그먼트)
6. Mac 관리 (desktopcomputer)
   └ 하위: Mac 시스템 관리 화면
7. USB 드라이브 (externaldrive)
   └ 하위: 외장 드라이브 정리 화면 (독립 승격, 창 제목 HanTool 유지)
8. 서버 현황 (chart.bar.xaxis)
   └ 하위: 서버 상태 및 한도 인라인 뷰 (정지/알 수 없음 시 safe OFF/unknown 유지, NAS 내부 미조회)
---
9. 설정 (gearshape)
   └ 하위: 브라우저, 번역, 비서, 입력 도우미, Mac 관리, USB, 서버 (실제 기능과 1:1 매핑)
10. 사용 안내 (questionmark.circle)
   └ 하위: 시작 가이드 및 기능 도움말
```

## 2. 핵심 계약 및 불변조건 (Invariants & Contracts)

1. **위치 리프(Location Leaf)와 액션(Action) 분리**:
   - 트리에서 '진행 중', '완료 기록', 탭 항목 등은 선택 가능한 '위치'이며 현재 위치로 하이라이트됩니다.
   - '주소 직접 입력', '링크 붙여넣고 받기', '새 탭' 등은 '액션'이며 절대 현재 위치로 선택 표시되지 않습니다.
   - '주소 직접 입력'은 다운로드 화면의 URL 입력창에 포커스만 주며, '링크 붙여넣고 받기'는 사용자가 클릭했을 때만 클립보드의 링크를 일괄 다운로드합니다. 단순 트리 펼침 시 클립보드를 읽지 않습니다.

2. **자동 전개(Auto-reveal)와 독립 탭 닫기**:
   - 중앙 본문에서 세그먼트나 탭을 바꾸면 왼쪽 트리의 부모와 하위 리프가 자동으로 펼쳐지며 위치를 맞춥니다.
   - 브라우저 탭 닫기 버튼은 선택 영역과 분리된 독립 버튼이며, 마지막 남은 탭은 닫히지 않도록 안전 가드가 적용됩니다.

3. **글로벌 우측 비서 독 (Root-stable Global Dock)**:
   - 비서 대화창은 최상위 루트 수준에서 생명주기를 유지하여 메뉴를 전환해도 대화 내역이 끊기지 않습니다.
   - 좁은 창에서는 가독성을 위해 비서 독을 닫아둘 수 있으며, 숨겨진 웹페이지(AI 로그인, 백그라운드 뷰포트)의 내용은 외부로 자동 전송되지 않습니다.

4. **상단 단일 툴바와 맥락 팝오버**:
   - 상단 단일 번역 버튼을 클릭하면 즉시 번역/캡처가 실행되지 않고, 현재 화면 맥락에 맞는 옵션 팝오버만 열립니다.
   - 메일 화면에서는 현재 표시된 문서를 그대로 유지하며, `Mail에서 가져오기`는 명시적 버튼으로 분리되어 가져오기 성공 시 `번역 > 메일 번역`으로 위치가 이동합니다. 메일 삭제 및 첨부 이미지는 메일 본문에서 관리합니다.

5. **네트워크 속도 표시 및 지속성**:
   - 단일 `NetworkRateMonitor`를 공유하며, 상단 표시(기본값)와 macOS 메뉴막대 표시 중 선택할 수 있습니다. 설정값은 재실행 후에도 복원됩니다.

6. **설정 카테고리 1:1 분리**:
   - 본문의 상태 현황과 환경 설정을 분리하고, 실제 존재하는 기능(브라우저, 번역, 비서, 입력 도우미, Mac 관리, USB, 서버)만 1:1 매핑합니다. 불필요한 빈 설정 항목을 신설하지 않습니다.
